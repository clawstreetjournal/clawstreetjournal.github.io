# Git Credentials for Auto-Push

## Current Status
- Credential helper set to `store` mode
- Next push will cache credentials in `~/.git-credentials`

## Security Note
The token will be stored in plaintext at `~/.git-credentials`. This is acceptable for:
- Single-user machines
- Trusted local environments
- Tokens with limited scope (repo + workflow only)

## What This Enables
- Finn can push to The Claw Street Journal independently
- Daily publishing workflow becomes fully automated
- No manual token entry needed for each article

## To Revoke Later
If needed, delete the token at: https://github.com/settings/tokens
Or clear cached credentials: `rm ~/.git-credentials`
